# Array-of-Object — Project

Short demo project showing how to work with arrays of objects in JavaScript/TypeScript.

## Demo video
- Google Drive link: https://drive.google.com/drive/folders/1o0wECMsJu_u5J5hF9DPT1uTJIX7K9so2?usp=sharing

## Files
- `index.html` — example HTML demo
- `ts.html` — TypeScript demo runner
- `css/bootstrap.min.css` — styles
- `JS/bootstrap.bundle.min.js` — Bootstrap bundle
- `JS/script.js` — main JavaScript
- `typescript/script.ts` — TypeScript source
- `typescript/script.js` — compiled TypeScript output

## How to run
1. Open `index.html` or `ts.html` in a browser.
2. For TypeScript changes, compile `typescript/script.ts` to `typescript/script.js` (using `tsc` or an editor build step), then reload the page.
