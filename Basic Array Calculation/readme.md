# Basic Array Calculation

This project demonstrates basic array operations using JavaScript and TypeScript. It includes simple examples for working with arrays and a separate TypeScript version of the script.

## Video Explanation

You can find the full project walkthrough here:

[Drive folder link](https://drive.google.com/drive/folders/1XOsisFsYE1GwMpudLhzWfgSaOwDk7bE4?usp=sharing)

## Project Structure

- `index.html` - main HTML page
- `readme.md` - project notes and video link
- `typesript.html` - TypeScript demo page
- `css/bootstrap.min.css` - Bootstrap stylesheet
- `js/script.js` - JavaScript implementation
- `typescipt/script.js` - compiled script output
- `typescipt/script.ts` - TypeScript source

## Notes

- Open the HTML files in a browser to run the examples.
- The TypeScript files show the same logic in TypeScript form.
